# PTT Pocket

PTT Pocket 是為手機設計的非官方 PTT 網頁終端排版工具，嵌入 [PTT 官方網頁終端](https://term.ptt.cc/)，讓終端畫面隨瀏覽器可見空間調整。

## 可以做什麼

- 直接在嵌入的官方終端登入、瀏覽看板與輸入文字。
- 隨視窗大小、手機方向及鍵盤造成的可見空間變化調整終端框架。
- 自訂畫面寬度（0–100%）及上方留白（至少 0px），畫面固定水平置中。
- 在狹小空間等比縮放終端；寬度設為 0% 時隱藏畫面。
- 自動記住此瀏覽器的畫面設定，並可一鍵還原。
- 查看可見區域、終端框架尺寸與縮放比例，或另開官方網站。

## 使用限制

本工具只調整外層畫面，不讀取官方終端內容，也不儲存帳號或輸入文字；登入、連線、中文輸入與手機鍵盤行為由官方網站及瀏覽器處理。

手機鍵盤的自動調整取決於瀏覽器是否回報可見區域變化，浮動鍵盤可能需要手動調整畫面。縮小後的文字可能較小，實際觸控與輸入體驗仍需在手機上確認。

本工具依賴官方網站允許嵌入；若官方限制嵌入或畫面無法載入，請直接使用官方網站。
